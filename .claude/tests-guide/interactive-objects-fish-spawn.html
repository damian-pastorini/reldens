Verification: Player Fishes Repeatedly At The Same Spawn Without It Moving Or Respawning

Test: tests/e2e/test-interactive-objects.spec.js - player fishes repeatedly at the same spawn without it moving or respawning

Video: ▶ Watch video

What makes this different from the mining rock: the rock is a respawn object, it disappears on use and comes back at a server-picked random area, so that test has to follow it. The fish spawn is a plain timing object with collisionType: 2 (static) and no respawn behaviour, so it stays at one place and can be used again and again from the same spot. This test asserts exactly that: the world position never changes and every completed cycle rewards one more item.
